## 关于 MeshNetProtocol

MeshNetProtocol 是一个创新的分布式 VPN 协议，通过区块链技术和流量挖矿机制实现去中心化网络服务。

### 核心特性

- **实时结算**：通过 HTTP 402 支付协议，实时为每个流量块进行区块链结算
- **流量挖矿**：所有用户都可以贡献网络带宽获得数字代币奖励
- **多链支持**：支持 USDC 稳定币和自定义代币结算
- **去中心化**：完全去中心化架构，无单点故障
- **隐私保护**：端对端加密，确保用户隐私和数据安全

## 本地预览

使用任何 HTTP 服务器打开首页：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js
npx http-server

# 使用 PHP
php -S localhost:8000
```

然后在浏览器中打开 `http://localhost:8000`
