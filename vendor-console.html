Deploy Your Node

只需简单的 4 步，一键自动化构建您的私有供应节点。

1

选择并购买 VPS (Purchase VPS)

前往您喜欢的云服务商注册并部署一台新实例。如果没有偏好，可以从下方选择我们推荐的厂商：

DigitalOcean
最易用的入门级 VPS
Vultr
全球机房 · 小时计费
Hetzner
欧洲性价比之王

购买时**推荐**参考以下系统与配置（因为我们底层的 sing-box 内核拥有极强的跨平台兼容性，只要是主流 Linux 发行版均能完美运行）：

  • OS (操作系统): 推荐 Debian 11/12 或 Ubuntu 22.04/24.04 （同时也全面支持 CentOS 8+ 等 RPM 系系统）
  • Plan: 基础云计算 (Basic / Regular Performance 即可)
  • Size: 512MB 内存或 1GB 内存 (约 $2.5 - $5/月)
💡 遇到困难？尝试复制以下提示词问 AI：
"我需要购买一台用于搭建 sing-box 节点的 VPS。请帮我对比 DigitalOcean, Vultr 和 Hetzner 的基础套餐价格。我希望系统用 Debian 12，内存 1GB。请给我一份具体的新手购买图文步骤指南。"
2

通过 SSH 连接服务器

购买成功后，在 VPS 控制台后台可以找到新服务器的 IP 地址 和 Root 密码。打开你电脑上的终端 (Terminal) / PowerShell，输入以下命令并回车，按提示输入密码进行连接：

ssh root@你的服务器 IP
💡 不知道终端在哪里？尝试复制以下提示词问 AI：
"我是一个纯粹的新手小白，我使用的是 [Windows 11 / macOS] 系统。我现在有了一台 VPS，IP 是 1.1.1.1，并且有了 root 密码。请一步步教我如何使用自带的 [PowerShell / 终端] 通过 SSH 登录上这台服务器，请告诉我每一步该点哪里、输入什么，详细到回车键。"
3

运行一键安装脚本

成功登录服务器后，复制并粘贴下面的全自动安装脚本到终端中执行。脚本会自动安装内核增强 (BBR)、配置防火墙规则，并部署 sing-box。整个过程大约需要 1-2 分钟。

bash <(curl -sL https://meshnetprotocol.github.io/install.sh)

如果系统已存在 sing-box，脚本会提示并退出。需要强制重装并覆盖配置时执行：

bash <(curl -sL https://meshnetprotocol.github.io/install.sh) --force
4

获取连接凭证

安装完成后，终端界面会打印出一个带有绿色 [SUCCESS] 的表格，其中包含 服务器 IP、服务端口 (Port) 和 随机密码 (Password)。请保管好这三个信息。

如果忘记了端口或密码，可在服务器上再次执行以下命令查看当前配置：

bash <(curl -sL https://meshnetprotocol.github.io/install.sh) --show
