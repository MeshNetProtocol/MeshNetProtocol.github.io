Deploy Your Node on Vultr

只需简单的 4 步，一键自动化构建您的私有供应节点。

1

购买 Vultr 服务器 (Purchase VPS)

前往 Vultr 官网注册并部署一台新实例。请确保选择以下配置：

  • System: Ubuntu 22.04 LTS 或 24.04 LTS
  • Plan: Cloud Compute (Regular Performance 即可)
  • Location: 推荐选择日本(Tokyo)、新加坡(Singapore)或美国(Silicon Valley)
  • Size: 512MB 内存或 1GB 内存 ($2.5 - $5/月)
前往 Vultr 官网 ↗
2

通过 SSH 连接服务器

购买成功后，在 Vultr 面板可以找到服务器的 IP 地址 和 Root 密码。打开你电脑上的终端 (Terminal) / PowerShell，输入以下命令并回车，按提示输入密码进行连接：

ssh root@你的服务器IP
3

运行一键安装脚本

成功登录服务器后，复制并粘贴下面的全自动安装脚本到终端中执行。脚本会自动安装内核增强(BBR)、配置防火墙规则，并部署 sing-box。整个过程大约需要 1-2 分钟。

bash <(curl -sL https://raw.githubusercontent.com/MeshNetProtocol/scripts/main/install.sh)
4

获取连接凭证

安装完成后，终端界面会打印出一个带有绿色 [SUCCESS] 的表格，其中包含 服务器 IP、服务端口 (Port) 和 随机密码 (Password)。请保管好这三个信息。
