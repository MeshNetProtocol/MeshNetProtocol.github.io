购买与部署 VPS (Server Setup)

连接全球算力底座。选择合适的 VPS 服务商是建立高性能供应节点的开端，配合我们的自动化脚本即可一键变身运营商。

  • 厂商精选：推荐 DigitalOcean(易用)、Vultr(全球)、Hetzner(极致性价比) 等节点。
  • 自动化脚本：提供 sudo bash install.sh 一键安装包，自动配置内核转发与 BBR。
  • 运行环境：支持 Ubuntu 22.04+ 及 Debian 11+，最小仅需 512MB 内存即可流畅运行。
  • 安全性增强：脚本自动配置基础防火墙与 SSH 密钥校验，保护您的服务器不被扫描攻击。

生成配置文件 (Profile Builder)

为个人或特定圈子定制去中心化供应节点配置。生成的 JSON 包含加密基座与 x402 支付元数据，支持多服务器聚合。

  • 零门槛配置：傻瓜式输入 IP、端口、密码，自动生成标准 sing-box 核心配置。
  • 私密共享：配置仅存本地或由您托管在公网 Gist，通过 URL 拉取即可同步给好友。
  • 无中间商：流量不经过 MeshNet 公共市场检索，完全属于您的私有地下网络。
  • 多端兼容：一键生成符合全平台 MeshNet App 规范的统一数据结构。

高级实验室 (Advanced Labs)

MeshNet 开发者乐园。如果您精通 sing-box 协议，可以在此手动编写极其复杂的路由规则与分流逻辑。

  • 协议深钻：在 sing-box 基础上原生注入 x402 支付协议，支持按量、按时、按次等复杂结算。
  • 路由自定义：精准控制哪些流量走代理、哪些直连，甚至实现负载均衡与故障切换。
  • 模板库：内置常用的全平台通用加速模板、流媒体解锁模板等进阶 JSON 片段。
  • JSON 语法加固：内置校验引擎，确保您的每一行配置都符合 sing-box / MeshNet 标准。

格式: com.mesh.[unique].[version]

粘贴完整 URL 或域名，系统将自动提取根后缀。官方域名 (githubusercontent.com, workers.dev) 将被强制包含。
