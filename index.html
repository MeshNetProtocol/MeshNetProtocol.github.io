工作原理

1

连接节点

用户连接到 MeshNetProtocol 网络中的节点，选择最优的网络路径

2

流量传输

数据通过分布式网络传输，每个流量块被实时记录和验证

3

实时结算

通过 HTTP 402 协议，为每个流量块实时进行区块链结算

4

获得奖励

节点运营者通过贡献带宽获得代币奖励，用户享受隐私网络服务

常见问题

MeshNetProtocol 是什么？

MeshNetProtocol 是一个基于区块链的分布式 VPN 协议，通过实时结算和流量挖矿机制，让用户可以获得网络服务同时赚取收益。

如何开始使用？

连接到 MeshNetProtocol 网络，配置您的区块链钱包，即可开始享受 VPN 服务并参与流量挖矿。

流量挖矿如何工作？

通过运行节点并贡献网络带宽，您可以获得流量挖矿奖励。系统会根据您贡献的带宽量实时计算奖励。

支持哪些支付方式？

目前支持 USDC 稳定币结算，同时支持项目自定义的代币结算方案。

是否安全隐私？

MeshNetProtocol 采用端对端加密和去中心化架构，确保用户的隐私和数据安全。

什么是 HTTP 402 支付协议？

HTTP 402 是一个互联网标准支付协议，允许对网络资源进行实时、粒度化的支付结算，非常适合按流量结算的场景。
